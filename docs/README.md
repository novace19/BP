# Text bakalářské práce

[Pracovní verze ve Wordu](Bakalarska_prace_fitness_pracovni_verze.docx) zachovává dodanou šablonu VŠPJ a názvy kapitol. Popisuje implementaci Forma Fitness v PHP a MySQL/MariaDB, relační model, rezervační pravidla, rozhraní a doložené automatické testy.

Kontrolní render má 57 stran, tedy 54 stran po odečtení prvních tří. Počet zahrnuje přední náležitosti, hlavní text, literaturu a přílohy. Dokument obsahuje 8 obrázků, 23 tabulek a 5 výpisů kódu. Ve Wordu se při jiných dostupných písmech může stránkování mírně lišit.

Popis aplikace vychází z verze `68e9314c26f160e364f8df4f0404a225dad06a43` a výsledku [běhu 40370990970](https://github.com/novace19/BP/actions/runs/40370990970): 35 HTTP kontrol, 28 integračních kontrol a úspěšný prohlížečový scénář. Nejde o tvrzení o zátěžovém nebo penetračním testování.

Před odevzdáním doplňte oficiální zadávací list z IS, poděkování a osobní/formální údaje. Zkontrolujte shodu cíle se zvoleným PHP: dříve dodaný text uváděl serverový JavaScript. Evidence použití AI je v závěrečné příloze; musí odpovídat skutečným pravidlům školy a dohodě s vedoucí. Dokument je pracovní znění k vlastnímu ověření, úpravám a konzultaci.
